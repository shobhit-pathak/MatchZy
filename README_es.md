MatchZy - Plugin de Partidas para CS2!
==============

MatchZy es un plugin para CS2 (Counter Strike 2) para gestionar y organizar prácticas/pugs/scrims/partidos con configuración fácil!

[![Discord](https://discordapp.com/api/guilds/1169549878490304574/widget.png?style=banner2)](https://discord.gg/2zvhy9m7qg)

## Principales Funcionalidades:

* Modo Pug con comandos simples para gestionar!
* Soporte a [Get5 Panel!](https://shobhit-pathak.github.io/MatchZy/get5/)
* Soporte BO1/BO3/BO5 y Veto al usar configuración de partida o Get5 Panel!
* [Configurar partidas](https://shobhit-pathak.github.io/MatchZy/match_setup/) y posicionar jugadores en sus equipos
* Modo Entrenamiento con `.bot`, `.spawn`, `.ctspawn`, `.tspawn`, `.nobots`, `.rethrow`, `.last`, `.timer`, `.clear`, `.exitprac` y muchos más comandos!
* Ronda de Cuchillo (Con lógica esperada, ej: el equipo con más jugadores gana. Si hay igual número de jugadores, el equipo con ventaja de HP gana. Si HP igual, el ganador se decide aleatoriamente)
* Inicia grabación de demo automáticamente y deja de grabar cuando la partida termina (Asegúrate de tener tv_enable 1)
* Carga automáticamente la demo al final del mapa en la URL proporcionada.
* Whitelist de jugadores (Gracias a [DEAFPS](https://github.com/DEAFPS)!)
* Sistema de coaching
* Reporte de daño después de cada ronda
* Soporte para restauración de rondas (Actualmente usando el sistema de backup estándar de Valve)
* Capacidad de crear administradores y permitirles acceso a comandos administrativos
* Estadísticas en Base de Datos y CSV! MatchZy almacena datos y estadísticas de todas las partidas en una base de datos SQLite local (Base de datos MySQL también es soportada!) y también crea un archivo CSV con estadísticas detalladas de cada jugador en la partida!
* Proporciona configuración fácil
* ¡Y mucho más!!
