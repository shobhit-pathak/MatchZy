MatchZy - Plugin de Partidas para CS2!
==============

MatchZy é um plugin para CS2 (Counter Strike 2) para gerenciar e organizar práticas/pugs/scrims/partidas com configuração fácil!

[![Discord](https://discordapp.com/api/guilds/1169549878490304574/widget.png?style=banner2)](https://discord.gg/2zvhy9m7qg)

## Principais Funcionalidades:

* Modo Pug com comandos simples para gerenciar!
* Suporte ao [Get5 Panel!](https://shobhit-pathak.github.io/MatchZy/get5/)
* Suporte BO1/BO3/BO5 e Veto ao usar configuração de partida ou Get5 Panel!
* [Configurar partidas](https://shobhit-pathak.github.io/MatchZy/match_setup/) e posicionar jogadores em seus times
* Modo Treino com `.bot`, `.spawn`, `.ctspawn`, `.tspawn`, `.nobots`, `.rethrow`, `.last`, `.timer`, `.clear`, `.exitprac` e muitos outros comandos!
* Ronda de faca (Com lógica esperada, ex: time com mais jogadores vence. Se número igual de jogadores, o time com vantagem de HP vence. Se HP igual, o vencedor é decidido aleatoriamente)
* Inicia gravação de demo automaticamente e para de gravar quando a partida termina (Certifique-se de ter tv_enable 1)
* Faz upload automático da demo no fim do mapa na URL fornecida.
* Whitelisting de jogadores (Graças a [DEAFPS](https://github.com/DEAFPS)!)
* Sistema de coaching
* Relatório de dano após cada ronda
* Suporte para restauração de rondas (Atualmente usando o sistema de backup padrão da Valve)
* Capacidade de criar administradores e permitir acesso a comandos administrativos
* Estatísticas no Banco de Dados e em CSV! MatchZy armazena dados e estatísticas de todas as partidas em um banco de dados SQLite local (Banco de dados MySQL também é suportado!) e também cria um arquivo CSV com estatísticas detalhadas de cada jogador na partida!
* Fornece configuração fácil
* E muito mais!!
