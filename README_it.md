MatchZy - Plugin Partite per CS2!
==============

MatchZy è un plugin per CS2 (Counter Strike 2) per gestire partite di pratica/pugs/scrims con facilità di configurazione!

[![Discord](https://discordapp.com/api/guilds/1169549878490304574/widget.png?style=banner2)](https://discord.gg/2zvhy9m7qg)

## Principali Funzionalità:

* Modalità Pug con comandi semplici da gestire!
* Supporto a [Get5 Panel!](https://shobhit-pathak.github.io/MatchZy/get5/)
* Supporto BO1/BO3/BO5 e Veto usando configurazione partita o Get5 Panel!
* [Configurare partite](https://shobhit-pathak.github.io/MatchZy/match_setup/) e posizionare i giocatori nelle loro squadre
* Modalità Allenamento con `.bot`, `.spawn`, `.ctspawn`, `.tspawn`, `.nobots`, `.rethrow`, `.last`, `.timer`, `.clear`, `.exitprac` e molti altri comandi!
* Round di Coltello (Con logica attesa, es: la squadra con più giocatori vince. Se stesso numero di giocatori, la squadra con vantaggio HP vince. Se HP uguale, il vincitore viene deciso casualmente)
* Avvia automaticamente la registrazione demo e ferma la registrazione quando la partita finisce (Assicurati di avere tv_enable 1)
* Carica automaticamente la demo alla fine della mappa sull'URL fornito.
* Whitelist dei giocatori (Grazie a [DEAFPS](https://github.com/DEAFPS)!)
* Sistema di coaching
* Report danni dopo ogni round
* Supporto per ripristino round (Attualmente usando il sistema di backup vanilla della Valve)
* Possibilità di creare admin e concedere loro accesso ai comandi admin
* Statistiche Database e CSV! MatchZy memorizza dati e statistiche di tutte le partite in un database SQLite locale (Database MySQL anche supportato!) e crea anche un file CSV con statistiche dettagliate di ogni giocatore nella partita!
* Configurazione facile
* E molto altro!!
